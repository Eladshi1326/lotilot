# הבוט של לוטי לוט — התקנה על Google Apps Script

## למה דווקא כאן

מפעל הפיס חוסם שרתי ענן. מדדנו את זה בפועל:

| מאיפה רצה הבקשה | תשתית | התוצאה |
|---|---|---|
| Netlify (הפונקציה של האתר) | AWS | ❌ נחסם |
| GitHub Actions | Azure | ❌ HTTP 403 |
| הסביבה שבה נבדק הפרויקט | Google Cloud | ✅ עובד |

Apps Script רץ על התשתית של גוגל — אותה רשת שכן עוברת. הוא גם חינם לגמרי,
בלי כרטיס אשראי ובלי תקופת ניסיון שנגמרת.

המכסות של חשבון gmail רגיל, מול מה שהבוט צורך:

| מכסה | מותר | הבוט צורך |
|---|---|---|
| בקשות רשת ביום | 20,000 | ~800 (כל רבע שעה, 8 בקשות) |
| זמן ריצה של טריגרים ביום | 90 דקות | ~13 דקות |
| זמן לכל הרצה | 6 דקות | ~10 שניות |

## התקנה — פעם אחת, בערך 10 דקות

### 1. יוצרים את הטוקן של גיטהאב

GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token

- Repository access: **Only select repositories** → `lotilot`
- Permissions → Repository permissions → **Contents: Read and write**
- מעתיקים את הטוקן. הוא מוצג פעם אחת בלבד.

> הטוקן הזה נותן גישת כתיבה לריפו. שומרים אותו רק בשלב 3 למטה — לא בקוד,
> לא בצ'אט, לא בקובץ בפרויקט.

### 2. יוצרים את הפרויקט

[script.google.com](https://script.google.com) → **New project** → מוחקים את מה
שכתוב שם ומדביקים את כל התוכן של `Code.gs`.

### 3. שומרים את הטוקן

Project Settings (גלגל השיניים בצד) → Script Properties → **Add script property**:

```
Property: GITHUB_TOKEN
Value:    <הטוקן מהשלב הראשון>
```

### 4. בודקים שהפיס בכלל עונה — זה הרגע המכריע

בוחרים בתפריט הפונקציות את **`testPais`** ולוחצים Run. מאשרים את ההרשאות
(גוגל תציג אזהרה "Google hasn't verified this app" כי זה סקריפט פרטי —
Advanced → Go to project).

בלוג אמור להופיע:

```
✅ lotto — הפיס עונה. שורה אחרונה שהוגרלה: 3951,01/08/2026,12,14,16,18,32,33,7,...
```

אם מופיע `❌ ... HTTP 403` בכל ארבעת המשחקים — הפיס חוסם גם את גוגל,
והמסלול הזה לא יעבוד. זאת הבדיקה שחוסכת את כל שאר העבודה, ולכן היא ראשונה.

### 5. בודקים את גיטהאב

מריצים **`testGithub`**. אמור להופיע:

```
✅ מחובר ל-Eladshi1326/lotilot | הרשאת כתיבה: יש
```

### 6. הרצה ראשונה אמיתית

מריצים **`updateLottery`**. אמור להופיע `✅ עודכן בגיטהאב`, ובריפו יופיע
commit חדש בשם "עדכון נתוני הפיס". האתר יראה את הנתונים תוך דקה.

### 7. מפעילים את הטריגר

Triggers (סמל השעון בתפריט הצד) → **Add Trigger**:

| שדה | ערך |
|---|---|
| Function to run | `updateLottery` |
| Event source | Time-driven |
| Type of time based trigger | Minutes timer |
| Minute interval | Every 15 minutes |

מכאן זה עובד לבד.

## איך יודעים שהוא באמת רץ

שלוש דרכים, מהמהירה לעמוקה:

1. **באתר** — למעלה מופיע "🤖 הבוט משך תוצאות מהפיס לפני X דקות". אם עברו
   יותר מ-90 דקות החיווי הופך לאדום.
2. **בגיטהאב** — לקובץ `pais-raw.json` יש commit חדש כל רבע שעה.
3. **ב-Apps Script** — Executions (סמל הרשימה בצד) מציג כל הרצה, כמה זמן
   לקחה, ומה נכשל.

## אם משהו נשבר

| מה רואים | מה זה אומר |
|---|---|
| `חסר GITHUB_TOKEN ב-Script Properties` | שלב 3 לא בוצע, או ששם המאפיין לא מדויק |
| `GitHub PUT 403` | לטוקן אין `Contents: Read and write` |
| `GitHub PUT 409` | שתי הרצות התנגשו — ההרצה הבאה תסתדר לבד |
| `HTTP 403` מהפיס | הפיס חוסם גם את גוגל |
| הטריגר מפסיק לרוץ | גוגל מכבה טריגרים שנכשלים ברצף — Executions יראה למה |

## בלי הבוט

האתר לא תלוי בו. `push-to-git.cmd` מייצר את `pais-raw.json` בכל דחיפה
מהמחשב, ואפשר גם להריץ ידנית `npm run pais-raw`. הבוט רק חוסך את הידיים.
