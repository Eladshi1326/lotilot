# 🎱 לוטי לוט

ניסוי חברתי: כל משתמש נכנס, לוחץ **פעם אחת** על הכרטיס הדיגיטלי — ומקבל 6 מספרים רנדומליים (1–37) + מספר חזק (1–7), בדיוק כמו בלוטו. הכרטיס של כל אחד מוצג לכולם בלוח המשותף, והמטרה: לבדוק אחרי כל הגרלה אמיתית אם מישהו מאיתנו *היה* זוכה.

## איך מפעילים? (הכי פשוט)

לוחצים פעמיים על **`start-dev.cmd`** — זה עושה הכול לבד:

1. בודק ש־Node.js מותקן (ואם לא — פותח את דף ההורדה)
2. מתקין תלויות בפעם הראשונה (`npm install`)
3. פותח את התיקייה ב־VS Code
4. פותח חלון CMD נוסף שמריץ את האתר, מעדכן את היסטוריית ההגרלות ממפעל הפיס ופותח את הדפדפן

האתר רץ בכתובת: `http://localhost:5173` (השרת עצמו על `http://localhost:3001`)

## העלאה לגיט

לוחצים פעמיים על **`push-to-git.cmd`**. אם עוד לא חובר ריפו — הקובץ יסביר בדיוק מה להריץ (שורת `git remote add origin ...` אחת) ומהפעם הבאה הכול יעלה בלחיצה.

## פקודות שימושיות

| פקודה | מה היא עושה |
|---|---|
| `npm run dev` | הרצת האתר לפיתוח (שרת + React עם רענון חי) |
| `npm run update-data` | עדכון ידני של היסטוריית ההגרלות ממפעל הפיס |
| `npm run build` | בניית גרסת production לתיקיית `dist` |
| `npm start` | הרצת production: שרת אחד שמגיש הכול (אחרי build) |

## מבנה הפרויקט

```
לוטי לוט/
├─ start-dev.cmd        ← הפעלה בלחיצה כפולה
├─ push-to-git.cmd      ← העלאה לגיט בלחיצה כפולה
├─ client/              ← האתר (React + Vite)
│  └─ src/components/   ← הכרטיס, הלוח המשותף, ההיסטוריה
├─ server/
│  ├─ index.mjs         ← שרת Express: API + הגשת האתר
│  └─ data/
│     ├─ lotto-history.json  ← היסטוריית הגרלות אמיתית (מתעדכן אוטומטית)
│     └─ picks.json          ← הכרטיסים של המשתתפים (נוצר אוטומטית, לא עולה לגיט)
└─ scripts/update-data.mjs   ← מוריד את קובץ התוצאות המלא מאתר מפעל הפיס
```

## איך זה עובד מבפנים

- **הגרלת המספרים נעשית בשרת** (`crypto.randomInt`) — כדי שאי אפשר יהיה "לזייף" כרטיס מהדפדפן.
- **פעם אחת לכל משתמש**: לכל דפדפן נוצר מזהה אנונימי; מי שכבר מילא — רואה את הכרטיס שלו.
- **הלוח חי**: הדף מושך עדכונים כל 5 שניות, אז רואים כרטיסים חדשים של אחרים בלי לרענן.
- **היסטוריית הגרלות**: בכל הפעלה יורד קובץ התוצאות המלא (כל ההגרלות מאז 1968!) מהכתובת הרשמית של מפעל הפיס. בלי אינטרנט — נשארים עם הנתונים האחרונים שנשמרו.

## פרסום לאינטרנט (בהמשך)

האתר צריך שרת Node (בגלל השמירה המשותפת), אז GitHub Pages לבד לא יספיק. שירותים חינמיים שמתאימים: Render / Railway / Fly.io — מגדירים Build: `npm install && npm run build` ו־Start: `npm start`, וזהו.
